# Snaplet 分阶段实现计划

更新时间：2026-10-06。

目标：使用 Swift + AppKit 实现本机 iShot 的主要使用流程，逐阶段交付可运行版本；通过实测优化响应、内存和能耗。当前参考是本机 iShot 2.6.5 的设置和界面，不承诺尚未核对的所有隐藏功能已进入清单。

## 实施规则

- 每阶段交付一个可运行版本，并记录代码状态、自动检查、真实操作结果和剩余问题。
- “代码已实现”“编译通过”“实际使用验证通过”分别记录。阶段功能必须经过真实流程验证才能标记完成。
- 快捷键沿用本机 iShot 设置；只注册已实现功能的快捷键，避免无效入口。
- 在当前功能稳定后进入下一阶段。需要硬件、权限或外部服务的验收明确记录条件。
- 应用代码先保持 Swift；只有测量证明需要时才引入其他语言或第三方依赖。
- 每阶段形成 Git 提交；需要时增加修复提交。未经真实验证的代码不称为稳定发布。

## 当前检查结果

- Debug 应用构建和本地签名通过。
- 11 项自动测试通过：截图坐标转换、PNG 尺寸及颜色、快捷键解析和序列化、选区保留/移动/缩放/重置、冻结画面裁剪及连续保存。
- 真实界面检查：基础窗口、截图入口、权限提示、快捷键录入、取消录入、自定义组合键与默认组合键显示。
- 最新启动界面显示区域截图快捷键为 ⌥A，注册过程没有报告错误。
- 实际框选后工具栏保持显示，完成后读回剪贴板 PNG 为 400 × 200；空格保存后读回 PNG 同为 400 × 200；取消保存对话框恢复原选区。见 [截图交互记录](CAPTURE_INTERACTION.md)。
- 开发签名问题已修复；已验证进入框选并显示实际截图预览。详见 [故障记录](BUGS.md)。
- 待验收：在其他应用前台按实体键触发截图；剪贴板图片粘贴到外部应用；多显示器和真实 Retina；重复截图后的资源测量。
- 未测量 iShot 与 Snaplet 的 CPU、内存、延迟或能耗差异，不宣称性能已超过 iShot。

## 性能比较方法

在同一台 Mac、同一组显示器、相同分辨率、相同功能与操作条件下记录：待机内存和 CPU、快捷键到框选显示的延迟、截图到预览的延迟、大图编辑峰值内存、关闭预览后的回落、重复截图后的增长，以及录屏的帧率、掉帧、CPU 和能耗。明确测量工具与样本次数，分开列出应用进程和相关辅助进程，不仅比较安装包体积。

## 贴图子版本

按用户要求提前实现阶段 3 的基础贴图。截图工具栏的图钉或 ⌘P 将选区生成独立置顶窗口，支持多张、移动、滚轮/捏合及右下角缩放、原始大小恢复、原图复制/保存、关闭及菜单栏统一隐藏/显示。贴图无边框、无阴影，关闭控件仅悬停显示。

14 项单元测试通过；新增 3 项测试覆盖大图按比例适配、屏幕边缘位置和细长图尺寸。实际界面已确认工具栏按钮及 ⌘P 生成无边框、无阴影的 600 × 300 px 贴图，Esc 可关闭，⌘C 读回的剪贴板 PNG 保持 600 × 300。菜单栏剪贴板入口、多窗口统一隐藏/显示、真实跨桌面置顶和长期资源回落仍需进一步验收。

## 自动窗口选择子版本

提前加入阶段 4 的基础窗口范围识别：区域截图中悬停识别、单击选择、拖动框选，选择后沿用复制/保存/贴图操作。已通过单窗口真实识别和导出及自由框选回归。未实现独立 ⌥Z 模式、遮挡窗口内容还原、透明圆角和阴影导出。

## 标注与尺寸子版本（2026-10-06）

选区中新增基础标注编辑工具栏与蓝色实时像素尺寸标签。标注在冻结图像的坐标系内绘制，导出先裁剪冻结图像，再按原始像素比例合成选区内的标注，所有输出入口共用合成结果；保存取消或失败会恢复标注。多屏恢复焦点明确返回原选区所在屏幕。

Debug 构建及本地签名通过，19 项自动测试通过。新增测试覆盖撤销/重做分支和 2× 像素比例、非整数裁剪边界下的导出位置及尺寸。实际操作已确认矩形、箭头、文字、撤销/重做和取消保存恢复；预览显示带箭头的图片，复制后读回 PNG 为 800 × 500，与标签一致。其余工具、颜色面板、大图及不同显示器缩放比例仍需更完整的验收。马赛克、局部高亮、单个标注选择修改、独立图片编辑尚未实现，阶段 2 不标记全部完成。

## 文字编辑交互修正（2026-10-07）

修复文字不可移动和删除、大字号输入被截断、编辑按钮悬停用途不显示的问题。文字命中按显示文字的字体边界计算，重叠时选中最上层；单击选中后可拖动，双击重新输入，Delete / Backspace 或 × 删除。输入框按真实行高和内容宽度调整。编辑按钮共用截图层内即时提示，避免系统提示窗口在高层级截图窗口下不可见。标注历史改为记录文档状态，使新增、移动、修改和删除均支持撤销/重做。

修复前 `swift test --filter AnnotationInteractionTests` 确认文字拖动坐标不变、Delete 未删除、72 pt 文字输入框只有 32 pt 高，以及悬停没有界面内提示；修复后相同检查通过。全部 25 项自动测试、Debug 构建和本地签名通过。桌面操作接口先后出现 120 秒和 20 秒超时，本次未完成实际桌面操作复核；不将 AppKit 事件测试称为真实桌面验收。
