## 当前交互

- 进入截图时冻结桌面；鼠标松开只确定选区，不提交截图。
- 选区内部可拖动，八个控制点可缩放；重新框选清空选区。
- 工具栏：重新框选、预览、保存…、取消、完成。
- Enter / ⌘C / 双击选区 / 完成：复制 PNG 并退出。
- 空格：保存到设置目录并退出，默认 ~/Pictures/Snaplet；文件名含毫秒时间及随机后缀，避免重复截图覆盖。
- ⌘S / 保存…：选择文件路径；取消恢复同一冻结画面与选区。
- Esc / 右键 / 取消：退出，不播放完成音效。
- 完成、预览生成、成功复制或保存播放 macOS 系统截图音效；开关默认开启并持久化。未使用 iShot 的音频资源。

## 紧凑界面调整

参考用户提供的 iShot 截图，主窗口改为 620 × 360 pt 的侧栏设置布局，包含“截图”和“保存与声音”两页。两页切换、快捷键入口及保存位置/音效控件已通过原生界面检查。框选工具栏为 252 × 36 pt 的浅色单行图标栏，保留已实现的五个操作；未添加尚未实现的标注按钮。选区采用蓝色边框与控制点，尺寸提示贴近选区上边缘。

图标按钮使用鼠标进入/离开跟踪，立即显示功能名称及快捷键，提示直接绘制在截图遮罩内部。自动化工具未提供纯鼠标移动接口，悬停提示的触发仍需要手动确认；功能名称与快捷键同时保留在辅助功能描述中。
