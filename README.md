# Snaplet

使用 Swift + AppKit 开发的原生 macOS 截图与录屏工具。当前支持可调整选区、实时像素尺寸、标注编辑、确认工具栏、完成音效、预览、复制图片、保存 PNG，以及可修改并持久化的全局快捷键；编译和 35 项自动测试通过，已验证实际框选、工具栏确认复制、取消保存恢复选区及空格保存读回。基础贴图与截图标注已实现；区域/窗口范围/全屏录屏已实现，支持系统声音、麦克风、暂停/继续和 MP4 导出；滚动截图、OCR 尚未实现。录屏的真实桌面与音频设备验收仍待完成。

## 下载

当前预览版本：[Snaplet v0.2.0](https://github.com/JFSAS/Snaplet/releases/tag/v0.2.0)。下载 `Snaplet-v0.2.0-macos-arm64.zip`，解压后将 `Snaplet.app` 放入“应用程序”；适用于 Apple Silicon Mac、macOS 14 或更新版本。发布页提供 `SHA256SUMS.txt`。

安装包使用本地开发证书签名，尚无 Developer ID 签名或 Apple 公证。首次截图或录屏需要屏幕录制权限，启用麦克风还需要麦克风权限。

## 开发与运行

在项目目录执行：

```sh
make run
```

应用显示菜单栏图标和基础窗口。关闭窗口后应用继续常驻；通过菜单栏重新打开，或选择“退出 Snaplet”。

## 截图

1. 按默认全局快捷键 **⌥A（Option + A）**，点击“开始区域截图”，或在菜单栏选择“区域截图…”。默认值与本机 iShot 的区域截图设置一致。
2. 首次使用需要在系统设置 → 隐私与安全性 → 屏幕与系统音频录制中允许 Snaplet（不同系统版本可能显示为“屏幕录制”）。如系统要求，退出后重新启动应用。
3. 鼠标悬停会自动高亮所在窗口，单击选择窗口范围；也可以直接拖动框选。确定后保留选区并显示工具栏。拖动选区内部移动，拖动八个控制点调整大小；点击“重新框选”重新选择。一次截图限制在开始拖动的显示器内，暂不支持跨屏拼接。
4. 按 Enter、⌘C、双击选区或点击“完成 ✓”复制图片并结束截图；按空格直接保存 PNG，默认目录为 `~/Pictures/Snaplet`，可在主窗口修改。点击“保存…”（⌘S）选择文件路径，取消该对话框会恢复原选区。点击“预览”进入独立预览窗口。
5. Esc、右键或“取消”退出截图。截图完成、成功复制或保存时播放系统截图音效；主窗口可关闭音效，设置会持久化。松开鼠标和取消不会播放完成音效。

进入框选前使用 ScreenCaptureKit 单帧采集冻结各显示器，之后直接从冻结图像裁剪；不常驻录屏，选区调整不会重复采集。应用自己的窗口排除在捕获内容之外，退出框选后释放全屏图像；导出的裁剪图使用独立像素缓冲区。预览按比例显示，导出的 PNG 保留捕获像素尺寸；关闭预览后释放其图片引用。目前只保留一个预览窗口。

点击主窗口中的“截图快捷键”按钮后按下新的组合键，Esc 取消。组合键需包含 Command、Control 或 Option。设置保存在应用 UserDefaults 中；无法注册时提示更换，修改失败时尝试恢复原快捷键。系统全局热键使用 Carbon 接口，不需要辅助功能权限。

Snaplet 使用独占热键注册，避免一个按键同时触发两个截图工具。若 iShot 或其他应用仍占用 ⌥A，需先退出该工具，再重启 Snaplet；也可以为 Snaplet 修改快捷键。

```sh
make build      # Debug 应用：build/debug/Snaplet.app
make release    # Release 应用：build/release/Snaplet.app
```

打包脚本支持本地开发证书；对外分发需要另行配置正式签名与公证。当前打包的是本机架构。

## 开发签名与权限

可通过 `SNAPLET_SIGNING_IDENTITY` 环境变量指定已安装的代码签名证书，也可以在项目根目录创建 `.signing-identity`，写入一行证书名称。该文件不进入 Git。环境变量优先于文件。

未配置证书时回退为 ad-hoc 签名。这种签名的默认应用身份绑定可执行文件哈希，重新编译后可能出现“系统权限已开，但截图仍提示未授权”。开发时应使用同一证书签名不同构建，保持应用身份稳定。切换签名后，旧权限可能需要移除并重新添加一次；不要手动修改 TCC 数据库。

本地开发证书不等于可供公开分发的 Developer ID 签名。构建脚本不会安装证书或修改钥匙串信任设置。

配置证书后可运行 `./scripts/check-signing.sh`，验证不同编译产物能保持相同开发身份。已修复的权限故障详见 [故障记录](docs/BUGS.md)。

## 在 Xcode 中编辑

用 Xcode 打开 `Package.swift`。项目由 Swift Package Manager 管理，并非 `.xcodeproj`。可以在 Xcode 中编译和调试可执行目标；检查实际菜单栏应用行为时，使用 `make run` 启动包含 `Info.plist` 的 `.app` 包。

## 贴图

框选后点击图钉图标“贴图”，或按 ⌘P，将截图置顶显示。图片没有边框或阴影；关闭按钮仅在鼠标移入时显示。拖动图片移动，滚轮/触控板捏合缩放，右下角可拖动缩放。⌘0 恢复初始显示大小；⌘C 复制原图，⌘S 保存原始 PNG，Esc / ⌘W 关闭当前贴图。右键菜单提供相同操作。

菜单栏支持“剪贴板贴图”和“隐藏 / 显示全部贴图”；可以同时打开多张，关闭后释放图片引用。当前贴图只在本次运行期间保留，尚无历史图库、重启恢复、透明度及文本贴图；剪贴板贴图和统一隐藏/显示的全局快捷键尚未注册。

## 自动选择窗口

按 ⌥A 进入截图后，将鼠标移到窗口上即可看到范围高亮，单击选择后继续调整、复制、保存或贴图。窗口重叠时优先选择鼠标位置最前方的窗口；拖动超过 3 pt 则使用自由框选。窗口列表在进入截图时获取，不持续扫描。

当前按冻结桌面的窗口范围裁剪，保留该区域实际可见的内容；不会还原被其他窗口遮挡的部分，也不单独导出透明圆角或窗口阴影。跨显示器窗口仅选取当前显示器内的部分。无需额外申请辅助功能权限。

## 截图编辑与尺寸

框选或单击选择窗口后，选区左上方显示蓝色尺寸标签，例如 `800 × 500 px`。尺寸按冻结图像的实际像素比例计算，拖动框选、移动和调整边界时实时更新，与导出 PNG 的尺寸一致；悬停识别窗口时也显示尺寸。

选区下方的编辑工具栏提供矩形、椭圆、直线、箭头、画笔、文字和序号。点击工具后在选区内拖动绘制；文字工具单击后输入，Enter 确认；序号工具单击放置递增编号。颜色控件支持自定义颜色，粗细可选择 2 / 4 / 6 / 8 / 12 pt，文字字号随粗细调整。使用左侧指针工具返回选区移动与缩放。

⌘Z 撤销，⇧⌘Z 重做；撤销后绘制新标注会清除重做记录。重新框选会清除当前标注。标注固定在冻结画面的位置，调整选区会改变保留的画面范围，超出选区的标注会被裁掉。复制、保存、快速保存、预览和贴图都使用带标注的图片。取消保存会恢复选区和标注，并将焦点返回原显示器。

已实测矩形、箭头、文字输入、撤销/重做、取消保存恢复和箭头预览/复制；读回剪贴板 PNG 为 800 × 500 px。新增自动测试验证撤销历史及 Retina 下的标注导出坐标和像素尺寸。椭圆、直线、画笔、序号和自定义颜色仍需更全面的交互验收。

文字标注支持单击选中、拖动移动、双击修改；选中后按 Delete / Backspace 或点击选框旁的 × 删除。使用指针工具或文字工具都可以操作已有文字。Enter 确认输入后即可拖动；输入状态下鼠标用于选择文字。移动、修改和删除均支持撤销/重做。矩形、椭圆、直线、箭头、画笔及序号同样支持选中、拖动和删除；无需切换到指针工具，直接拖动已有标注即可移动。矩形和椭圆从边框拖动，线条、箭头及画笔从笔迹拖动，序号从圆形标记拖动。选中后按 Delete / Backspace 或点击 × 删除，重叠时优先选中最上层的可见笔迹。按住 Option 可以从已有标注处开始绘制新标注。图形的大小及端点调整尚未实现。

文字输入框按字体行高自动调整高度，随内容扩宽，最大不超过当前屏幕；长到超过屏幕宽度时横向滚动。编辑工具栏使用截图层内的即时悬停提示，显示工具用途和快捷键。马赛克、局部高亮和独立图片编辑尚未实现。

## 录屏（2026-10-07）

主窗口“录屏”页面提供以下设置，选择会持久化：

- 区域 / 窗口范围录制：拖动框选，或单击选择窗口范围；支持调整选区。按 Enter、空格或点击“开始录制”，倒计时 3 秒后开始实时录制。
- 全屏录制：录制鼠标所在的单个显示器，菜单栏也提供入口。
- 声音：无声音、系统声音、麦克风、系统声音 + 麦克风。首次使用麦克风需授权；权限提示在开始录制前显示。
- 画质：720p、1080p、原始像素（最高 4K）；保留选区比例，不放大小区域。H.264 编码使用偶数像素尺寸。
- 帧率：15 / 30 / 60 FPS；可选显示鼠标光标。

全局快捷键默认为 **⌥W 开始区域录屏**、**⌥P 暂停 / 继续**，可在录屏页面修改。若被 iShot 等其他应用占用，按钮悬停显示注册错误，可改用其他组合键；菜单栏与按钮入口仍可使用。

录制时红色边框标记固定区域，悬浮栏显示计时、暂停/继续和停止；可以拖动悬浮栏，菜单栏也可停止。倒计时期间可以取消。暂停的时间会从视频及音频时间轴移除。Snaplet 自身窗口、边框、控制栏及自身系统音频排除在录制之外。窗口模式录制的是选中的固定屏幕范围，不跟随窗口移动，也不还原被其他窗口遮挡的内容；不支持跨显示器拼接。

停止后输出 H.264/AAC MP4 到“保存与声音”中设置的目录（默认 `~/Pictures/Snaplet`），并在 Finder 中选中文件。系统音频与麦克风同时启用时，保存阶段将两路音频合并到单条可播放音轨；这一步需要额外处理时间及临时磁盘空间。录制中退出应用会等待视频保存完成；启动或暂停切换的短暂处理中需稍后再次退出。捕获意外停止时会尝试保存已收到的画面；写入失败显示错误，两路音频合并失败时保留原始文件以便恢复。

验证：34 项自动测试通过；新增 7 项覆盖暂停时间轴、尺寸/比例、媒体时间戳、空录制清理、录屏选区交互、静止画面 MP4 时长与解码，以及两路合成 PCM 声音导出为单条可解码音轨。Debug 构建与本地签名通过。桌面自动化接口连续超时，因此尚未完成实际点击、ScreenCaptureKit 实时画面、真实麦克风/系统声音、长时间同步与资源占用、多显示器和权限拒绝的设备验收。自动测试中的合成媒体不代表这些实测已通过。

GIF、鼠标点击高亮、摄像头画中画、独立录音和视频裁剪尚未实现。
