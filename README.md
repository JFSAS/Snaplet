# Snaplet

使用 Swift + AppKit 开发的原生 macOS 截图工具。当前支持可调整选区、确认工具栏、完成音效、预览、复制图片、保存 PNG，以及可修改并持久化的全局快捷键；编译和 11 项单元测试通过，已验证实际框选、工具栏确认复制、取消保存恢复选区及空格保存读回。基础贴图已实现；标注、滚动截图、OCR 和录屏尚未实现。

## 环境

- macOS 14 或更新版本
- Xcode 16 或更新版本，且已选择其命令行工具
- Swift 6.0 或更新版本
- 无第三方依赖

## 开发与运行

在项目目录执行：

```sh
make run
```

应用显示菜单栏图标和基础窗口。关闭窗口后应用继续常驻；通过菜单栏重新打开，或选择“退出 Snaplet”。

## 截图

1. 按默认全局快捷键 **⌥A（Option + A）**，点击“开始区域截图”，或在菜单栏选择“区域截图…”。默认值与本机 iShot 的区域截图设置一致。
2. 首次使用需要在系统设置 → 隐私与安全性 → 屏幕与系统音频录制中允许 Snaplet（不同系统版本可能显示为“屏幕录制”）。如系统要求，退出后重新启动应用。
3. 鼠标悬停会自动高亮所在窗口，单击选择窗口范围；也可以直接拖动框选。确定后保留选区并显示工具栏。拖动选区内部移动，拖动八个控制点调整大小；点击“重新框选”重新选择。一次截图限制在开始拖动的显示器内，暂不支持跨屏拼接。
4. 按 Enter、⌘C、双击选区或点击“完成 ✓”复制图片并结束截图；按空格直接保存 PNG，默认目录为 `~/Pictures/Snaplet`，可在主窗口修改。点击“保存…”（⌘S）选择文件路径，取消该对话框会恢复原选区。点击“预览”进入独立预览窗口。
5. Esc、右键或“取消”退出截图。截图完成、成功复制或保存时播放系统截图音效；主窗口可关闭音效，设置会持久化。松开鼠标和取消不会播放完成音效。

进入框选前使用 ScreenCaptureKit 单帧采集冻结各显示器，之后直接从冻结图像裁剪；不常驻录屏，选区调整不会重复采集。应用自己的窗口排除在捕获内容之外，退出框选后释放全屏图像；导出的裁剪图使用独立像素缓冲区。预览按比例显示，导出的 PNG 保留捕获像素尺寸；关闭预览后释放其图片引用。目前只保留一个预览窗口。

点击主窗口中的“截图快捷键”按钮后按下新的组合键，Esc 取消。组合键需包含 Command、Control 或 Option。设置保存在应用 UserDefaults 中；无法注册时提示更换，修改失败时尝试恢复原快捷键。系统全局热键使用 Carbon 接口，不需要辅助功能权限。

Snaplet 使用独占热键注册，避免一个按键同时触发两个截图工具。若 iShot 或其他应用仍占用 ⌥A，需先退出该工具，再重启 Snaplet；也可以为 Snaplet 修改快捷键。

```sh
make build      # Debug 应用：build/debug/Snaplet.app
make release    # Release 应用：build/release/Snaplet.app
```

打包脚本支持本地开发证书；对外分发需要另行配置正式签名与公证。当前打包的是本机架构。

## 开发签名与权限

可通过 `SNAPLET_SIGNING_IDENTITY` 环境变量指定已安装的代码签名证书，也可以在项目根目录创建 `.signing-identity`，写入一行证书名称。该文件不进入 Git。环境变量优先于文件。

未配置证书时回退为 ad-hoc 签名。这种签名的默认应用身份绑定可执行文件哈希，重新编译后可能出现“系统权限已开，但截图仍提示未授权”。开发时应使用同一证书签名不同构建，保持应用身份稳定。切换签名后，旧权限可能需要移除并重新添加一次；不要手动修改 TCC 数据库。

本地开发证书不等于可供公开分发的 Developer ID 签名。构建脚本不会安装证书或修改钥匙串信任设置。

配置证书后可运行 `./scripts/check-signing.sh`，验证不同编译产物能保持相同开发身份。已修复的权限故障详见 [故障记录](docs/BUGS.md)。

## 在 Xcode 中编辑

用 Xcode 打开 `Package.swift`。项目由 Swift Package Manager 管理，并非 `.xcodeproj`。可以在 Xcode 中编译和调试可执行目标；检查实际菜单栏应用行为时，使用 `make run` 启动包含 `Info.plist` 的 `.app` 包。

## 目录

```text
Sources/Snaplet/
  main.swift                 应用入口
  AppDelegate.swift          应用生命周期与菜单栏
  MainWindowController.swift 基础 AppKit 窗口
  CaptureCoordinator.swift   截图流程与权限提示
  SelectionOverlay.swift     冻结画面、框选控制点与确认工具栏
  SelectionModel.swift       框选、移动、缩放状态
  CaptureFeedback.swift      完成音效与开关
  CaptureOutput.swift        快速保存目录与文件命名
  CaptureService.swift       ScreenCaptureKit 单帧采集与 PNG 编码
  CapturePreviewController.swift 预览、复制和保存
  GlobalShortcut.swift       全局快捷键注册与录入
Resources/Info.plist          应用元数据
scripts/build-app.sh          编译、打包与本地签名
```

`swift test` 的 11 项测试覆盖框选状态、移动边界、控制点缩放、Retina 裁剪坐标、PNG 尺寸与颜色往返、连续保存，以及快捷键解析和序列化。交互约定与实测记录见 [截图交互](docs/CAPTURE_INTERACTION.md)。实际桌面捕获、多显示器/Retina 行为与全局快捷键需在授权后的图形会话中验证，单元测试不能替代这些检查。

## 贴图

框选后点击图钉图标“贴图”，或按 ⌘P，将截图置顶显示。图片没有边框或阴影；关闭按钮仅在鼠标移入时显示。拖动图片移动，滚轮/触控板捏合缩放，右下角可拖动缩放。⌘0 恢复初始显示大小；⌘C 复制原图，⌘S 保存原始 PNG，Esc / ⌘W 关闭当前贴图。右键菜单提供相同操作。

菜单栏支持“剪贴板贴图”和“隐藏 / 显示全部贴图”；可以同时打开多张，关闭后释放图片引用。当前贴图只在本次运行期间保留，尚无历史图库、重启恢复、透明度及文本贴图；剪贴板贴图和统一隐藏/显示的全局快捷键尚未注册。

## 自动选择窗口

按 ⌥A 进入截图后，将鼠标移到窗口上即可看到范围高亮，单击选择后继续调整、复制、保存或贴图。窗口重叠时优先选择鼠标位置最前方的窗口；拖动超过 3 pt 则使用自由框选。窗口列表在进入截图时获取，不持续扫描。

当前按冻结桌面的窗口范围裁剪，保留该区域实际可见的内容；不会还原被其他窗口遮挡的部分，也不单独导出透明圆角或窗口阴影。跨显示器窗口仅选取当前显示器内的部分。无需额外申请辅助功能权限。
